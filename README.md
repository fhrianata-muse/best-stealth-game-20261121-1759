Mothlight is a top-down stealth game played in the browser. You are a hooded
thief with a moth-lantern, stealing gold seals from three night archives
while guards patrol with lantern cones. Steal every seal, then slip out the
green exit unseen. Guards patrol waypoint loops, pause to scan, and chase
when the alarm rises — break line of sight and hide in the shadows to slip
away. Light sees you fast, shadow hides you, sneaking hides you further.
Guard footsteps grow louder as they near, so you can hear danger coming.

Controls: move with WASD / arrow keys or click to walk, sneak with Shift,
grab a seal with E (or walk over it), restart the room with R, mute with M.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
